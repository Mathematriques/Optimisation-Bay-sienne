# Optimisation-Bayésienne

Petit projet en python pour mieux comprendre les processus Gaussiens et leur utilisation en optimisation Bayésienne.
J'ai essayé de faire un script python par chapitre ou idée présentée dans https://bayesoptbook.com/book/bayesoptbook.pdf

Pour l'instant le but n'est pas de faire un code efficace mais surtout clair pour voir le lien entre la description mathématique et son implémentation.
Chaque script produit des animations ou des graphiques pour montrer ce lien, en essayant de rester fidèle à la présentation du livre.
